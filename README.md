# menu_QR

Aplicación web estática que muestra un menú digital a través de un QR. Ideal para restaurantes y cafeterías.

Descripción

Este repositorio contiene una página HTML/CSS/JS sencilla que despliega el menú de un local y permite generar un código QR o acceder mediante un enlace corto.

Características

- Menú organizado por categorías (entradas, platos, bebidas, postres)
- Visualización responsive para móviles
- Posibilidad de compartir el menú mediante QR

Instalación

1. Clona el repositorio:

   git clone https://github.com/barbarojob-lab/menu_QR.git
   cd menu_QR

2. Abre index.html en un navegador o despliega en GitHub Pages
